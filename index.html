    Sources & Limits

    Education uses the 2026 Gaode / AMap POI package because the course chat states the 2024 education data has a problem.

    Other POI categories use the provided 2023 Shanghai shapefiles. AQI uses the official Shanghai 2025 district daily export.

    Scores are H3 neighborhood proxy accessibility with an exported 500m grid proxy. True graph isochrones should replace this layer after the graph-tool environment is cleaned up.

    Metro distance and rent band are not directly measured in the provided Track A data; the detail panel shows transit proxy counts and marks rent as not collected.
